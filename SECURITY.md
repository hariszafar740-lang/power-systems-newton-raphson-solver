# Security Policy

## Supported Versions

| Version / Branch | Python Support | Supported |
|:--- |:--- |:---: |
| `main` (latest) | Python 3.10 – 3.13 | |
| Older commits | < 3.10 | |

## Scope & Operational Notice

This repository provides a numerical engineering simulation solver intended for research, benchmarking, and educational power-flow studies.
It is not certified for direct real-time SCADA/EMS substation control without independent utility-grade validation.

## Reporting a Vulnerability

If you discover a security issue (e.g., unsafe deserialization in data loaders, CI workflow vulnerabilities, or dependency CVEs).
Please report it privately via GitHub's Report a vulnerability advisory tab or open a minimal tracking notice without exploit payloads so a patch can be prepared promptly.
